## 關於 NewsRoom 新聞中心

歡迎來到 **NewsRoom**！這是一個專門用於發佈與管理合作夥伴新聞稿的官方入口網站。

### 平台特色

- **自動化發佈**：合作夥伴只需將新聞稿寄送至專屬電子信箱 `NewsRoom@edwardwu23.com`，系統將透過 Microsoft Power Automate 雲端工作流與 GitHub Actions，自動將郵件內容轉換為 Markdown 文章並發佈，實現全自動、無程式碼（No-Code）的內容管理。
- **簡約且響應式設計**：基於 Jekyll Chirpy 主題構建，支援深色與淺色模式切換，並具備完整的前端即時搜尋與標籤分類功能。
- **安全與高效**：靜態網頁託管於 GitHub Pages，無需資料庫與後端伺服器，保證極高的安全性與快速的頁面載入速度。

> **聯絡發佈**
> 若您有新聞稿發佈的需求或合作提案，請直接聯繫系統合作信箱：[NewsRoom@edwardwu23.com](mailto:NewsRoom@edwardwu23.com)。
